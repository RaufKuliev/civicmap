# Участие в проекте

Исправления данных должны быть проверяемыми и политически нейтральными. В issue укажите публичную страницу, точное изменение, прямой первичный источник и дату доступа.

## Локальная проверка

1. Установите Node.js 22 и pnpm 11.17.0.
2. Выполните `pnpm install --frozen-lockfile`.
3. Перед PR запустите `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm data:validate`, `pnpm data:coverage` и `pnpm build`.
4. Для изменений статической доставки дополнительно выполните `pnpm static:check` и subpath-сборку из README.

Не добавляйте биографии из поисковых сниппетов, личные контакты, недатированные статусы и координаты без проверенного источника. Сгенерированные отчёты должны воспроизводиться штатной командой. В PR отделяйте фактическое изменение от редакционного мнения.

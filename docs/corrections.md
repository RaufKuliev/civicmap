# Исправления данных

Исправление принимается через шаблон GitHub issue `Исправление данных`. Обязательны страница, точная формулировка, прямой первичный источник и дата доступа.

Редактор проверяет соответствие личности, смысл документа, дату и отсутствие конфликта с более новым источником. Изменение статуса добавляется новым событием, а не переписывает историю. Спорная запись получает явный статус проверки; предположение не публикуется как факт.

До создания удалённого репозитория форма сайта ничего не отправляет. После публикации владелец должен добавить канонический issue URL в интерфейс.

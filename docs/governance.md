# Управление проектом

Владелец репозитория назначает maintainers и редакторов данных. Код может быть принят после CI; фактическое изменение дополнительно требует первичного источника и редакционной проверки.

Роли не совмещают автоматическое доверие: автор импорта не должен единолично подтверждать спорную идентификацию. Существенные изменения схемы, методологии, лицензии, провайдера геокодирования и политики приватности фиксируются в PR и release notes.

До назначения владельцем публичных контактов решения по эскалациям остаются блокером релиза.

# Методология данных

Базовый срез кандидатов — заверенные партийные списки на 18 июля 2026 года. Статус `certified_list` означает только включение в заверенный список. Статус `registered` присваивается по датированному решению комиссии; сейчас импортировано 16 решений ОИК округов № 201–202, актуальных на 14 августа 2026 года.

Схема кандидата хранит источник, дату факта и хронологию статуса. Legacy-записи детерминированно мигрируют в v2 в памяти. Snapshot manifest и diff не перезаписывают прошлые события.

Названия 225 округов извлечены из приложения к закону и сохранены дословно. Они не содержат полного юридического состава границ. Структурированные подписи используются только для поиска; все 225 помечены `review_required`. Проверенных полигонов — 0/225.

Проверяемая команда: `pnpm data:validate`; измерение пробелов: `pnpm data:coverage`. Отсутствующая биография, контакт, ресурс или публикация отображается как отсутствие редакционной проверки, а не как отсутствие факта в реальности.

# Приватность

Сайт не содержит аккаунтов, cookies, аналитики и серверной базы пользовательских запросов. Фильтры поиска хранятся только в URL по действию пользователя.

Адрес отправляется внешнему геокодеру только после нажатия «Найти», если владелец включил endpoint. CIVIC MAP не записывает адрес и координаты в `localStorage`, cookies или файлы; пяти минутный кэш существует только в памяти текущей вкладки. Внешний провайдер может обрабатывать IP-адрес и запрос по собственной политике.

Не вводите адрес, если не согласны на передачу включённому провайдеру. Локальный fallback по названиям работает без внешнего запроса, когда endpoint отключён.

# Финальный QA перед публикацией

Дата проверки: 14 августа 2026 года. Проверка относится к локальному состоянию репозитория до первого commit и не означает, что сайт опубликован.

## Результаты проходов

**Текст и достоверность.** Основные и динамические страницы проверены по маршрутам. Заглушек и конфликтующих подписей статусов не найдено. На карточках округа и кандидата показаны дата актуальности, источник/основание, ограничения данных и ссылка на исправление. Улучшение: поисковая выдача получила корректную семантику live-region вместо неполного ARIA listbox.

**Состояния интерфейса.** Проверены обычное, пустое, частичное, ошибочное, неоднозначное и 404-состояния. Короткий адрес даёт локальное сообщение, сбой геокодера сохраняет текстовый fallback, а отсутствие проверенной геометрии не превращается в точное назначение округа.

**Крайние вводы и география.** Длинный запрос со специальными символами отображается как текст, не создаёт DOM script и не вызывает горизонтальный overflow. Пустые и короткие адреса, неизвестный адрес, совпадение по региону и пограничная/множественная геометрия покрыты browser- и unit-тестами.

**Безопасность и приватность.** В клиентском коде не найдены `eval`, `dangerouslySetInnerHTML`, Web Storage или небезопасные ссылки с `target="_blank"`. Адрес отправляется только после явного действия, не сохраняется и обрабатывается с throttle, timeout, abort и памятью с TTL. `pnpm audit --prod` не нашёл известных уязвимостей; secret/large-file audit чист.

**Доступность.** Добавлены skip-link, контрастный focus outline, читаемые placeholder-цвета, доступное имя кнопки поиска и подпись мобильной навигации. Browser-тест проверяет клавиатурный переход к `main`, reduced motion, подписи полей, landmarks и внешние ссылки. Минимальная измеренная контрастность основных текстовых пар — 4,57:1, что проходит WCAG AA для обычного текста.

**Responsive и визуальная целостность.** Главные поверхности проверены при desktop и 390×844. Автотест подтверждает нулевой горизонтальный overflow на главной, поиске, изменениях, адресе, методологии, исправлениях, регионе, округе, кандидате и 404. Финальные снимки: `docs/screenshots/final-home-desktop.png` и `docs/screenshots/final-candidate-mobile.png`.

**Производительность и артефакт.** Экспорт содержит 1 993 HTML-маршрута и 61 130 внутренних ссылок без разрывов. Подпутевой artifact занимает 170 846 612 байт; HTML поиска — 35 056 из лимита 250 000, индекс поиска — 666 501 из лимита 800 000. Запрещённых архивов в `out/` нет.

**Репозиторий.** Проверены 3 workflow, 589 release-файлов до добавления этого отчёта, 0 secret hits, 0 файлов больше 2 МБ и 0 remote. `git diff --stat` пуст, потому что репозиторий инициализирован без первого commit; вместо несуществующего baseline проверен полный набор будущих Git-файлов через `git ls-files --cached --others --exclude-standard`.

**Регрессия.** Root и `/civicmap` exports проходят link audit и browser-сценарии. Финальные typecheck, lint, unit-тесты, data validation, evidence QA и coverage должны завершаться с exit 0.

## Нерешённые решения владельца

`pnpm release:check` намеренно завершается с exit 1, пока не указаны GitHub owner, лицензия, security/editorial contacts, подтверждение условий источников, включение Pages, решение по custom domain и политика production-геокодера. Эти решения не подменяются техническими предположениями.

# Политика адресного поиска

Адрес обрабатывается только в браузере по явному нажатию кнопки. CIVIC MAP не сохраняет строку адреса и координаты в cookies, `localStorage`, аналитику или файлы проекта.

## Провайдер

Клиент использует заменяемый Nominatim-совместимый endpoint из `NEXT_PUBLIC_GEOCODER_ENDPOINT`. Если переменная не задана, внешний запрос отключён, но локальный поиск по названиям регионов и территориальным меткам продолжает работать.

Запросы выполняются только после отправки формы, не чаще одного раза в 1,1 секунды. Результат хранится пять минут только в памяти вкладки. Тайм-аут — восемь секунд; новый запрос отменяет предыдущий. Для публичного Nominatim владелец развёртывания обязан отдельно проверить актуальную usage policy, обеспечить атрибуцию OpenStreetMap и не превращать форму в autocomplete.

## Точность

Точный округ возвращается только когда координата находится внутри ровно одного полигона из `data/geometry/verified-districts.json`. Точка на границе, пересечение нескольких полигонов и отсутствие проверенной геометрии считаются неоднозначным или неподдерживаемым результатом.

Текущий реестр содержит 0/225 проверенных геометрий. Поэтому локальная подсказка показывает только возможные округа по официальным названиям территорий и всегда помечает их как неточные.
